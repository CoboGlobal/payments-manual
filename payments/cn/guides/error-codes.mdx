本文介绍了在使用 Cobo Payments API 时可能遇到的常见错误码和 HTTP 状态码，以及如何解决这些错误。

### 错误码

| 错误码 | 描述 | 解决方案 |
|---|---|---|
| 1006, 2006 | 一个或多个参数格式无效或包含不支持的值。 | 以预期格式提供有效参数。常见原因：缺少必填字段、字段值使用了不支持的枚举字符串、金额格式小数位数过多，或值超出允许范围。请查阅 API 参考文档了解特定字段约束和有效值。 注意：许多特定领域的错误——例如不支持的代币、资源未找到或应用层余额不足——也会以错误码 2006 的形式返回。当您收到 2006 时，请检查 error_message 字段以确定具体的子类型。 |
| 2001 | MFA 验证失败。 | 敏感操作（如创建提款）需要多因素认证，但请求中缺少 X-MFA-UUID 请求头，或提供的 MFA 令牌无效或已过期。<ul><li>在请求中包含有效的 X-MFA-UUID 请求头。</li><li>确保 MFA 令牌通过 MFA 验证流程获取且未过期。</li><li>如果 MFA 验证失败，请重新发起 MFA 流程以获取新令牌后再重试。</li></ul> |
| 2010, 2026 | API 请求频率超出限制。 | <ul><li>在客户端实现指数退避和重试逻辑。</li><li>降低 API 调用频率。</li><li>查阅定价计划中记录的频率限制。</li></ul>注意：错误码 2010 为支付服务频率限制；错误码 2026 为 WaaS2 平台级频率限制。两者均返回 HTTP 429。 |
| 2023 | API 请求签名缺失或无效。 | <ul><li>确保请求时间戳与服务器时间相差不超过 30 秒。</li><li>验证请求体是否按照正确、一致的键顺序进行序列化。</li><li>确认使用的密钥对与当前环境对应（开发环境与生产环境）。</li></ul>详情请参见<a href="/payments/cn/developer-tools/get-started-with-api">发送首个请求</a>。 |
| 2024 | API Key 认证失败。 | <ul><li>请使用与当前环境对应的 API Key（例如开发环境使用开发 API Key，生产环境使用生产 API Key）。</li><li>请确保您使用的 API Key 已在 Cobo Portal 上注册并状态为活跃中。</li><li>如果您的 API Key 是永久的，请确保请求来自白名单 IP 地址。</li><li>确保您的 API Key 已激活。新创建的 API Key 在使用前可能需要在 Cobo Portal 中激活。</li></ul>详情请参见<a href="/payments/cn/developer-tools/get-started-with-api">发送首个请求</a>。 |
| 2028 | 请求的资源不存在。 | <ul><li>验证资源标识符是否正确且未被误复制。</li><li>在另一请求中引用资源前，确保该资源已成功创建。</li><li>确认 API Key 与拥有该资源的组织属于同一组织。</li></ul>注意：当 API 端点有效但资源不存在时，响应体中返回错误码 2028。HTTP 404 表示端点 URL 本身不正确。 |
| 2050 | 无可用定价计划，或操作使用量已超出限制。 | 请联系 Cobo 销售团队审查或升级您的计划。 |
| 2051 | 您的定价计划已过期。 | 通过 Cobo Portal 续期或升级，或联系 Cobo 销售团队。 |
| 2052 | 您的计划使用量已超出限制。 | 请联系 Cobo 销售团队升级您的计划。 |
| 3000 | 测试代币领取配额已耗尽。 | 您的组织已达到开发环境中每组织最多领取 10 次测试代币的上限。请联系 Cobo 支持团队申请增加测试代币领取配额。 |
| 4001 | 禁止访问请求的资源。 | <ul><li>您的 API Key 缺少访问该端点所需的权限。</li><li>API Key 在不同环境（开发环境与生产环境）中创建。</li><li>该资源属于其他组织。</li><li>您正在访问当前计划中未包含的功能。</li></ul>完整权限矩阵请参考<a href="/payments/cn/guides/roles-and-permissions">角色与权限</a>。 |
| 4002 | 组织支付服务状态无效。 | <ul><li>登录 Cobo Portal 并检查您的支付服务账户状态。</li><li>如果账户处于待审核状态，请等待审批或联系您的 Cobo 客户经理。</li><li>如果账户已被暂停，请联系 Cobo 支持团队获取帮助。</li></ul> |

### HTTP 状态码

| 状态码 | 描述        | 解决方案                                    |
| --------------- | ---------------------- | ----------------------------------------------- |
| 200             | 成功。                    | 不适用              |
| 400             | 错误请求。           | 检查请求参数。                   |
| 401             | 未经授权。          | 检查 API Key、API 签名或时间戳。 |
| 403             | 禁止访问。             | 确保您具有所需权限。       |
| 404             | 未找到。             | 检查请求 URL。                           |
| 405             | 方法不允许。    | 使用支持的 HTTP 方法。                    |
| 406             | 不可接受。        | 确保请求内容格式为 JSON。      |
| 429             | 请求过多。     | 降低请求频率并稍后重试。详情请参见业务错误码 2010 和 2026。   |
| 500             | 内部服务器错误。此错误可能由多个问题引起。| 检查您的服务器配置设置并稍后重试。                              |
| 502             | 错误网关。           | 检查连接并稍后重试。     |
| 503             | 服务不可用。   | 稍后重试。                                |
