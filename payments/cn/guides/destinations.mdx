本指南介绍了如何通过 Cobo Payment API 集成和管理**转出目的地（Destination）**。
转出目的地，是用于出金（Payout）和批量下发（Bulksend）的收款实体，用于聚合多个钱包地址或者多个用于法币结算的银行账户。

核心功能：
- **收款目的地管理**： 将加密货币钱包地址和法币银行账户整合在单一实体下。
- **提币白名单**： 作为加密货币出金的白名单库，限制资金仅能提取至白名单中的钱包地址。
- **商户关联**： 每个支付商户（Merchant）可关联特定的转出目的地，实现为商户便捷出金。注意，暂不支持直接结算法币到商户银行账户。
- **风险防控**： 集成Cobo Premium服务后，支持对地址进行风险扫描。在添加转出目的地或者出金交易前识别有风险的钱包地址。



- 如需 Off-Ramp 对接，您需录入与您公司主体名称一致的银行账户，并通过 Cobo 运营团队的审核，审核通过后方可用于出金操作。

- 进行加密货币转账时，您可通过**将转出目的地设为白名单**开关，灵活管理可转账的地址范围：
  - 若开启该开关，则仅允许转账至已录入的转出目的地（钱包地址）；
  - 若关闭该开关，则可自由输入目标地址，或从已录入的转出目的地中选择。

## 录入转出目的地

您可以在 Payments App 中录入转出目的地，并添加钱包地址和银行账户。

如需在三方下发流程中使用 Python SDK 创建目标银行账户，请参阅[三方下发 Python SDK 集成](/payments/cn/developer-tools/third-party-payout-python-sdk)。

### 权限要求

仅**支付管理员**和**管理员**角色拥有创建、编辑与删除转出目的地的权限。**支付成员**仅有浏览权限，无法进行修改操作。

### 具体步骤

1. 登录 Cobo Portal [开发环境](https://portal.dev.cobo.com/login)或[生产环境](https://portal.cobo.com/login)。
2. 在左侧导航栏中点击 **Apps**，然后点击 **Payments** 卡片，启动 App。
3. 在 App 的左侧导航栏中点击**资金管理** > **转出目的地**。
4. 点击右上角的**添加转出目的地**按钮。
5. 在弹出的表单中，填写需录入的钱包地址和/或银行账户信息。  
   <img src="/payments/cn/images/payments/create-destination.png" className="screenshot_full_screen" alt="录入转出目的地" />
   - 如果录入的是钱包地址，您可以选择将其与某个商户关联。关联后，为该商户发起资金转出时，系统会自动为其选用该钱包地址作为目的地，提升操作便捷性和准确性。  
   - 如需添加银行账户，请确保账户名称与公司主体一致。
6. 点击**提交**，并完成身份验证。
7. 如果您录入了银行账户，则还需等待 Cobo 运营团队审核通过后，方可使用该银行账户进行出金。
