本文介绍如何将您收到的加密货币转账至外部加密货币地址。

## 1. 创建加密货币转账请求

您可以通过 Payments App 或 Payments API 创建加密货币转账请求。

<Tabs>
  <Tab title="Payments App" icon="pager">
    1. 登录 Cobo Portal [开发环境](https://portal.dev.cobo.com/login)或[生产环境](https://portal.cobo.com/login)。
    2. 在左侧导航栏中点击 **Apps**，然后点击 **Payments** 卡片，启动 App。
    3. 在 App 的左侧导航栏中点击**资金管理** \> **余额**。
    4. 您可以选择提取**商户余额**或**开发者余额**。在本例中，我们选择提取商户余额。点击**商户余额**卡片上的**出金**按钮。
    5. 在弹窗中，选择**发送加密货币**。

       <img
         src="/payments/cn/images/payments/crypto-payout.png"
         className="screenshot_full_screen"
         alt="加密货币转账入口"
         title=""
       />
    6. 填写转账信息，商户名称选择后不可修改，需要填写收款代币及网络、接收地址、发送金额。

       <Note>
         如果您在**转出目的地**中开启了**将转出目的地设为白名单**的开关，则仅可以转出至已录入的转出目的地。更多详情请参考[转出目的地](/payments/cn/guides/destinations)
       </Note>
    7. **自动选择资金来源**：当开关开启时，您只需要填写总发送金额，系统自动根据您钱包内各代币的可用余额分配出金金额；开关关闭时，你需要自行填写各代币的出金金额。该开关默认开启，您可关闭。
    8. **跨链**：当您出金特定链的 USDT 或者 USDC 资产时，可使用您钱包内**其他链的** USDT 或者 USDC 资产跨链后转出。特别的，目前仅支持同资产跨链，暂不支持不同资产兑换。
       - **收费**：同资产跨链会收取一定的费用，根据您发送金额自动计算。
       - **举例**：当前转出账户内可用余额：150 Tron USDT，50 ETH USDT。总发送金额 200 Tron USDT，则需对 50 ETH USDT 进行跨链，跨链手续费 10 ETH USDT，预计接收金额 190 Tron USDT。
    9. 按照页面提示确认并提交转账请求。
  </Tab>
  <Tab title="Payments API" icon="code">
    1. 在创建转账请求前，您可以调用 [List merchant balances](/payments/en/api-references/payment/list-merchant-balances) 或 [Get developer balance](/payments/en/api-references/payment/get-developer-balance) 分别查询商户和开发者余额，用于确定可转账的最大金额。
    2. 调用 [Create Payout](/payments/en/api-references/payment/create-payout) 创建转账请求。

    **基础参数**

    - `request_id`：您提供的唯一请求 ID，用于跟踪转账请求
    - `source_account`：付款来源账户。当从商户账户出金时，传入商户 ID；当从开发者账户出金时，设置为 `developer`。
    - `payout_channel`：设置为 `Crypto`，加密货币转账

    **关键参数说明**

    | Schema             | 相关参数                 |
    | ------------------ | -------------------- |
    | **payout_params**  | `amount`、`token_id`  |
    | **recipient_info** | `token_id`、`address` |

    加密货币转账要求 **recipient_info** 中同时提供 `address` 和 `token_id`。

    **参数说明：**

    - `amount`：加密货币金额，以十进制字符串形式提供。忽略小数末尾的零后，小数部分最多保留两位；例如 `100.500`（等同于 `100.5`）可以接受，但 `100.567` 在忽略末尾零后仍有三位小数，会导致请求失败，且系统不会对金额进行四舍五入。
    - `token_id`：加密货币 ID（如 `ETH_USDT`、`TRON_USDT`）。当 **payout_params** 和 **recipient_info** 中的 `token_id` 币种相同但链不同时，Cobo 会自动执行跨链操作。
    - `address`：目标加密货币地址。
  </Tab>
</Tabs>

## 2. 自动资金归集

在处理您的转账请求前，Cobo 会检查您商户或开发者账户中的可用资金总额是否足以覆盖本次转出金额。

资金总额是否充足的判断依据是账户的账本余额。有关该余额的具体计算方式，请参考[账户与资金分配](/payments/cn/guides/amounts-and-balances#余额)。

如果总资金充足，但其中一部分资金仍留存在收款地址中（例如用于收取订单模式或充值模式款项的地址），尚未归集至您的余额，Cobo 会在处理转账请求的过程中自动完成这部分资金的归集。您无需另行提交归集请求——只要转账请求需要，该步骤都会自动执行。

资金归集进行期间，转账请求会保持 `Pending` 状态。如果某次归集尝试失败，Cobo 会自动重试；您无需手动重新发起转账请求或执行任何操作。如果转账请求保持 `Pending` 状态的时间超过预期，请调用 [Get payout information](/payments/en/api-references/payment/get-payout-information) 重新查询其状态。

<Note>
  该自动归集是转账流程中的一个内部环节，与此前（已废弃）可由您手动发起的 [Create forced sweep](/payments/en/api-references/payment/create-forced-sweep) 和 [List forced sweeps](/payments/en/api-references/payment/list-forced-sweeps) 操作不同，现在无需再手动发起归集。
</Note>

## 3. 完成二次确认、风控审核及交易签名

在创建转账请求后，基于您的提交方式、风控设置等因素，需要完成以下操作：

- 二次确认：如您通过 Payments App 进行转账，则需要在 Cobo Guard 上确认该转账请求。
- 风控审核：如果您设置了交易风控，则可能需要审批员在 Cobo Guard 上批准该转账请求。
- 交易签名：如果您使用的是 MPC 钱包，则需要移动端签名人或服务端签名人签名，方可最终完成转账操作。

## 4. 跟进转账状态

您可以订阅 `payment.payout.status.updated` 事件，获取转账状态的实时更新。请参考 [Webhook reference](/payments/cn/guides/status-and-events) 了解每个事件的详细触发条件和返回的数据结构。

您也可以通过 Payments App 或 Payments API 主动查询转账请求状态。

<Tabs>
  <Tab title="Payments App" icon="pager">
    1. 登录 Cobo Portal [开发环境](https://portal.dev.cobo.com/login)或[生产环境](https://portal.cobo.com/login)。
    2. 在左侧导航栏中点击 **Apps**，然后点击 **Payments** 卡片，启动 App。
    3. 在 App 的左侧导航栏中点击**资金管理** \> **余额**。
    4. 在商户账户或者开发者账户详情页，**最近活动-加密货币转账**标签页查看所有转账请求的状态和详情。
  </Tab>
  <Tab title="Payments API" icon="code">
    您可以调用以下 API 操作查询转账请求状态：

    - [Get payout information](/payments/en/api-references/payment/get-payout-information) - 查询单个转账请求的详细信息
    - [List all payouts](/payments/en/api-references/payment/list-all-payouts) - 查询所有转账请求的详细信息
  </Tab>
</Tabs>

## 5. 资金转出退回

Payout reversal 适用于收款方将已完成的加密货币转账资金在链上退回到 Payment 收款地址或出金来源地址的情况。该场景不能通过 [Create Refund API](/payments/en/api-references/payment/create-refund-order) 发起或处理，因为 Create Refund 仅用于收款订单退款。

退回资金被检测到并通过合规筛查后，会按意外入账处理。您可以接收 `payment.transaction.external.completed` 事件，并在相关 Payment 余额页面核对入账金额。原资金转出记录仍保持已完成的资金转出记录；退回资金不会在该笔资金转出上生成专门的 Payout reversal 状态。

如需处理退回的出金资金，请联系 Cobo 支持团队，并提供原资金转出 ID、退回交易哈希、币种、网络、金额，以及接收退回资金的地址。
