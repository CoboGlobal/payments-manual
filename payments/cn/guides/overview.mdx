Cobo 支付解决方案是一套完整的加密货币支付基础设施，涵盖收付款、资金管理、合规筛查、商户管理等核心功能，为企业级客户提供安全、合规、高效的一站式支付服务。该解决方案广泛适用于以下业务场景：

- SaaS 服务商
- 独立电商网站
- 全球薪资发放
- 支付服务提供商（PSP）
- 其他需要加密货币支付的业务场景


## 业务流程

Cobo 支付解决方案的整体业务流程如下：
<Info>有关 Cobo 支付解决方案提供的完整功能清单和详细说明，请参考[功能列表](/payments/cn/guides/features)。</Info>
<img src="/payments/cn/images/payments/overview.png" className="diagram" alt="Cobo 支付解决方案的整体业务流程"></img>


1. **收款阶段**：向付款方收取加密货币。您可以根据业务需求选择不同的[收款模式](/payments/cn/guides/features#收款)。
2. **资金管理阶段**：Cobo 会对收到的资金进行合规筛查，确保交易安全合规。同时，Cobo 会自动将分散在不同地址的资金进行归集，便于您集中管理资金并进行后续操作，如加密货币兑换、跨链、购买理财产品等。
3. **资金转出阶段**：您可以将加密货币兑换成法币后，转入您的银行账户，或直接将加密货币转账至外部钱包地址。

## 订单模式与充值模式对比

Cobo 支付解决方案在收款阶段提供两种收款模式。订单模式针对具体订单创建带有有效期的指定金额支付请求，适合一次性结账或账单收款场景；充值模式为付款方分配一个持久地址，支持重复、金额可变的资金充值，例如持续的账户充值。

| 对比维度 | 订单模式 | 充值模式 |
| :-- | :-- | :-- |
| 支付模式 | 针对具体订单创建的一次性支付请求。 | 为付款方在特定链上分配的持久地址。 |
| 金额处理 | 订单创建时即固定应付金额，可直接指定，或通过定价与汇率计算得出。 | 付款方可随时向该地址充值任意金额。 |
| 有效期 | 订单具有有效期，付款方需在该时限内完成支付，否则订单过期。 | 地址没有有效期限制，可重复用于充值，直至您主动更换。 |
| 地址生命周期 | 每笔订单生成一个收款地址。 | 为每个付款方在每条链上创建专属充值地址，需要时可更换。 |
| 状态/交易跟踪 | 订单状态（如 `Pending`、`Completed`、`Underpaid`、`Expired`）以及 `payment.status.updated`、`payment.transaction.late`、`payment.transaction.completed` 等 Webhook 事件。 | `payment.transaction.created`、`payment.transaction.completed` 等 Webhook 事件，按付款方跟踪。 |
| 推荐场景 | 金额和支付时限已提前确定的一次性结账或账单收款。 | 金额不固定的重复性资金充值，例如账户或钱包充值。 |

有关具体实现，请参考[订单模式收款](/payments/cn/guides/create-orders)和[充值模式收款](/payments/cn/guides/get-topup-addresses)。
