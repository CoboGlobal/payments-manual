---
title: "意外入金"
lang: "zh-hans"
---

不属于任何入金计划、也不属于任何订单的入金，或者币种不受支持的入金，不会作为充值或订单收款处理，而是作为意外入金上报。它计入您的开发者余额，不计入某个付款方或某笔订单。请先阅读[事件概述](/payments/cn/guides/events/overview)了解外层结构、去重方式以及所有事件通用的规则。

## 本页的事件

| 事件 | 通知什么 | 什么时候需要订阅 |
| --- | --- | --- |
| [`payment.transaction.external.created`](#payment-transaction-external) | 检测到一笔意外入金。 | 必选。这类入金不属于任何付款方或订单，没有别的事件会告诉您它到了。 |
| [`payment.transaction.external.completed`](#payment-transaction-external) | 该笔入金通过筛查，已计入您的开发者余额。 | 必选。同上，这一条告诉您它已经入账。 |

## `payment.transaction.external.*`

### 事件触发条件

| 事件 | 触发时机 | 您该做什么 |
| --- | --- | --- |
| `payment.transaction.external.created` | 检测到一笔不属于任何入金计划或订单的入金，或者入金币种不受支持。 | 建立一条待归属的记录。**此时资金尚未入账。** |
| `payment.transaction.external.completed` | 该笔入金通过合规筛查，资金已计入您的开发者余额。 | 按您自己的规则处理这笔无法归属的资金——退回付款方、人工归属到某个付款方，或计入平台收入。 |

这两个事件不会出现在任何订单的 `transactions` 数组里，也不会产生 `payment.topup.updated`。如果您需要核对流入自己地址的每一笔资金，这是唯一的来源。

### 事件内容

| 字段 | 说明 |
| --- | --- |
| `transaction_id` | 该笔入金的交易 ID。联系支持时提供它。 |
| `status` | 交易状态。`created` 时为处理中，`completed` 时为 `Completed`。 |
| `chain_id` / `token_id` | 这笔入金所在的链与币种。**币种不受支持正是它成为意外入金的常见原因之一**，所以这里可能出现您没有开通的 token。 |
| `transaction_hash` | 链上交易哈希。广播前可能为空。 |
| `source` | 资金来源，通常是一个外部钱包地址。要退回付款方时用它。 |
| `destination` | 资金去向，包含收款地址 `address`、到账金额 `amount`，部分链还有 `memo`。 |
| `confirmed_num` / `confirming_threshold` | 已获得的确认数，以及该链认定安全所需的确认数。 |
| `created_timestamp` / `updated_timestamp` | 创建时间与最近更新时间，Unix 时间戳（毫秒）。 |

完整的交易字段清单见[高级事件](/payments/cn/guides/events/advanced#交易字段)——上表是与意外入金处理有关的那些。

### 示例事件

以下示例只展示 `data` 对象。外层结构所有事件都一样，参见[事件结构](/payments/cn/guides/events/overview#事件结构)。

#### 检测到一笔意外入金

先记录，不要入账。

```json
{
  "data_type": "PaymentTransaction",
  "transaction_id": "7b3c9d1e-4444-4a5b-8c6d-000000000001",
  "status": "Submitted",
  "chain_id": "TRON",
  "token_id": "TRON_USDT",
  "transaction_hash": "0xexternal001",
  "source": { "source_type": "DepositFromAddress", "address": "0xunknown_sender" },
  "destination": { "destination_type": "DepositToAddress", "address": "0xtopup_addr_M1001_user_abc", "amount": "35.00" },
  "confirmed_num": 0,
  "confirming_threshold": 19,
  "created_timestamp": 1744730000000,
  "updated_timestamp": 1744730000000
}
```

#### 意外入金已计入开发者余额

资金已经在您的开发者余额里，按您自己的规则处理。

```json
{
  "data_type": "PaymentTransaction",
  "transaction_id": "7b3c9d1e-4444-4a5b-8c6d-000000000001",
  "status": "Completed",
  "chain_id": "TRON",
  "token_id": "TRON_USDT",
  "transaction_hash": "0xexternal001",
  "source": { "source_type": "DepositFromAddress", "address": "0xunknown_sender" },
  "destination": { "destination_type": "DepositToAddress", "address": "0xtopup_addr_M1001_user_abc", "amount": "35.00" },
  "confirmed_num": 19,
  "confirming_threshold": 19,
  "created_timestamp": 1744730000000,
  "updated_timestamp": 1744730600000
}
```
