本页的事件汇报通过[结算网络](/payments/cn/guides/settlement-network)结算的转账。请先阅读[事件概述](/payments/cn/guides/events/overview)了解外层结构、去重方式以及所有事件通用的规则。

## 本页的事件

| 事件 | 通知什么 | 什么时候需要订阅 |
| --- | --- | --- |
| [`payment.transaction.settlement_network.created`](#paymenttransactionsettlement_network) | 创建了一笔结算网络交易。 | 必选（使用结算网络时）。 |
| [`payment.transaction.settlement_network.completed`](#paymenttransactionsettlement_network) | 该交易完成，结算资金已到您的 Payment 账户余额。 | 必选（使用结算网络时）。到账金额看余额事件。 |

## `payment.transaction.settlement_network.*`

两个事件携带的基础字段见[高级事件](/payments/cn/guides/events/advanced#交易字段)，没有额外的 Payment 字段。

交易完成时，结算资金会以 `SettlementNetwork` 这个 `source_type` 反映到您的 Payment 账户余额。到账金额由对应的 [`payment.account.balance.updated`](/payments/cn/guides/events/balances) 事件告知——本页这两个事件携带的是交易而不是余额。

### 示例

以下示例只展示 `data` 对象。外层结构所有事件都一样，参见[事件结构](/payments/cn/guides/events/overview#事件结构)。

#### 一笔结算网络交易完成

事件携带的是交易而不是到账金额，金额请看对应的余额事件。

```json
{
  "data_type": "PaymentTransaction",
  "transaction_id": "5c4b3a2d-9999-4f1e-8b7a-000000000001",
  "status": "Completed",
  "chain_id": "ETH",
  "token_id": "ETH_USDC",
  "transaction_hash": "0xsettlement001",
  "source": { "source_type": "DepositFromAddress" },
  "destination": { "destination_type": "DepositToAddress" },
  "confirmed_num": 12,
  "confirming_threshold": 12,
  "created_timestamp": 1744720000000,
  "updated_timestamp": 1744720600000
}
```

随后的余额事件会告诉您到账了多少：

```json
{
  "data_type": "PaymentAccountBalanceUpdate",
  "source_account": "developer",
  "source_id": "5c4b3a2d-9999-4f1e-8b7a-000000000001",
  "source_type": "SettlementNetwork",
  "token_id": "ETH_USDC",
  "amount": "1000.00",
  "amount_raw": "1000.000000",
  "balance_before": "332.00",
  "balance_before_raw": "332.000000",
  "balance_after": "1332.00",
  "balance_after_raw": "1332.000000",
  "flow_direction": "in",
  "update_time": 1744720600
}
```
