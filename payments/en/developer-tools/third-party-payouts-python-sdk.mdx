This guide shows how to use the Cobo WaaS 2.0 Python SDK (`cobo_waas2`) to build a third-party payout integration. The workflow covers SDK initialization, required file uploads, merchant KYC submission, destination bank account creation, and off-ramp payout creation.

For SDK installation and base configuration, see [Get started with Python SDK](/payments/en/developer-tools/quickstart-python). For behavior and status details, see [Off-ramp](/payments/en/guides/fiat-payouts), [Destinations](/payments/en/guides/destinations), and [Merchant management](/payments/en/guides/merchants).

## Prerequisites

- Install and configure the Python SDK by following [Get started with Python SDK](/payments/en/developer-tools/quickstart-python).
- Create or identify the merchant that will submit KYC information. For merchant setup concepts, see [Merchant management](/payments/en/guides/merchants).
- Prepare the local files required for merchant KYC and bank account binding.
- Prepare the destination bank account information used for the off-ramp payout.

## Initialize the Python SDK

Create a `Configuration` object with your API private key and the API host, then instantiate `PaymentApi`.

```python
import cobo_waas2
from cobo_waas2 import ApiClient
from cobo_waas2.api.payment_api import PaymentApi

configuration = cobo_waas2.Configuration(
    api_private_key="your_api_private_key",
    host="https://api.sandbox.cobo.com/v2",
)
api_client = ApiClient(configuration)
api_instance = PaymentApi(api_client)
```

## Upload required files

Use `upload_payment_file_v2` to upload local documents needed by later API operations, such as merchant KYC attachments or the bank account binding contract file. The API returns a `file_id` that you reference in later requests.

API operation: [Upload file V2](/payments/en/api-references/payment/upload-file-v2).

```python
import base64
import os

from cobo_waas2.models.payment_upload_file_v2 import PaymentUploadFileV2


def create_file(file_path: str):
    with open(file_path, "rb") as f:
        file_bytes = f.read()
    file_content = base64.b64encode(file_bytes).decode("ascii")
    print(f"file size = {len(file_bytes)} bytes")
    print(f"file_content size = {len(file_content)} bytes")
    response = api_instance.upload_payment_file_v2(
        payment_upload_file_v2=PaymentUploadFileV2(
            file_name=os.path.basename(file_path),
            file_content=file_content,
        )
    )
    print(response)
    return response
```

## Create an off-ramp payout

Use `create_payout` to submit the payout request. Set `payout_channel` to `PayoutChannel.OFFRAMP`, provide a client-generated UUID in `request_id`, specify the source merchant in `source_account`, and pass the destination bank account ID in `recipient_info.bank_account_id`.

API operation: [Create payout](/payments/en/api-references/payment/create-payout).

```python
import uuid

from cobo_waas2.models.create_payout_request import CreatePayoutRequest
from cobo_waas2.models.payment_payout_param import PaymentPayoutParam
from cobo_waas2.models.payment_payout_recipient_info import PaymentPayoutRecipientInfo
from cobo_waas2.models.payout_channel import PayoutChannel


def create_payout():
    response = api_instance.create_payout(
        create_payout_request=CreatePayoutRequest(
            request_id=str(uuid.uuid4()),
            payout_channel=PayoutChannel.OFFRAMP,
            source_account="M1001",
            payout_params=[
                PaymentPayoutParam(
                    token_id="TTRON_USDT",
                    amount="90",
                )
            ],
            remark="test",
            recipient_info=PaymentPayoutRecipientInfo(
                currency="USD",
                bank_account_id="47de9ef9-2c73-4dd8-ae6c-467a0258ca58",
            ),
        )
    )
    print(response)
    return response
```
