This guide shows how to use the Cobo Payments Python SDK (`cobo_waas2`) to complete an end-to-end third-party payout flow. The flow covers SDK configuration, file upload, merchant KYC submission, destination bank account creation, and off-ramp payout creation.

Use this guide when you want to implement the payout workflow in code. For broader concepts, see [Off-ramp](/payments/en/guides/fiat-payouts), [Destinations](/payments/en/guides/destinations), and [Merchant management](/payments/en/guides/merchants).

## Prerequisites

- You have completed the setup in [Get started with Python SDK](/payments/en/developer-tools/quickstart-python).
- You have an API private key that can call Payments API operations.
- You have the local files required for KYC verification or bank account binding.
- You have the merchant ID that you use as the source account for merchant-level payout operations.

## Install and configure the Python SDK

Install the SDK and configure `PaymentApi` with your API private key and API host.

```python
import cobo_waas2
from cobo_waas2 import ApiClient
from cobo_waas2.api.payment_api import PaymentApi

configuration = cobo_waas2.Configuration(
    api_private_key="your_api_private_key",
    host="https://api.sandbox.cobo.com/v2",
)

api_client = ApiClient(configuration)
api_instance = PaymentApi(api_client)
```

## Upload files

Upload files that are required for merchant KYC verification or bank account binding. The SDK request reads a local file, Base64-encodes the binary content, and calls `upload_payment_file_v2`. The response includes a `file_id` that you can reference in later requests.

```python
import base64
import os


def create_file(file_path: str):
    with open(file_path, "rb") as f:
        file_bytes = f.read()

    file_content = base64.b64encode(file_bytes).decode("ascii")

    print(f"file size = {len(file_bytes)} bytes")
    print(f"file_content size = {len(file_content)} bytes")

    response = api_instance.upload_payment_file_v2(
        payment_upload_file_v2=PaymentUploadFileV2(
            file_name=os.path.basename(file_path),
            file_content=file_content,
        )
    )

    print(response)
    return response
```

## Create an off-ramp payout

Create an off-ramp payout by calling `create_payout`. Generate a unique `request_id` for idempotency, set `payout_channel` to `PayoutChannel.OFFRAMP`, and pass the destination bank account ID in `recipient_info.bank_account_id`.

```python
import uuid


def create_payout():
    response = api_instance.create_payout(
        create_payout_request=CreatePayoutRequest(
            request_id=str(uuid.uuid4()),
            payout_channel=PayoutChannel.OFFRAMP,
            source_account="M1001",
            payout_params=[
                PaymentPayoutParam(
                    token_id="TTRON_USDT",
                    amount="90",
                )
            ],
            remark="test",
            recipient_info=PaymentPayoutRecipientInfo(
                currency="USD",
                bank_account_id="47de9ef9-2c73-4dd8-ae6c-467a0258ca58",
            ),
        )
    )

    print(response)
    return response
```
