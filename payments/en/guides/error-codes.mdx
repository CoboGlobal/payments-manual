This article explains the common error codes and HTTP status codes you may encounter when using the Cobo Payments API and how to resolve the errors. 

### Error codes

| Error code | Description | Solution |
|---|---|---|
| 1006, 2006 | One or more parameters are in an invalid format or contain unsupported values. | Provide valid parameters in the expected format. Common causes: a required field is missing, a field value uses an unsupported enum string, the amount format has too many decimal places, or a value is outside the allowed range. Check the API reference for the specific field constraints and valid values. Note: Many domain-specific errors (such as unsupported token, resource not found, or insufficient application-layer balance) also surface as code 2006. When you receive 2006, inspect the error_message field to identify the specific sub-case. |
| 2001 | MFA verification failed. | A sensitive operation (such as creating a payout) requires multi-factor authentication, but the X-MFA-UUID header is absent, or the provided MFA token is invalid or expired. <ul><li>Include a valid X-MFA-UUID header in your request.</li><li>Ensure the MFA token was obtained through the MFA verification flow and has not expired.</li><li>If MFA verification fails, re-initiate the MFA flow to obtain a fresh token before retrying.</li></ul> |
| 2010, 2026 | API request rate limit exceeded. | <ul><li>Implement exponential back-off and retry logic in your client.</li><li>Reduce the frequency of API calls.</li><li>Review the rate limits documented in your pricing plan.</li></ul>Note: Code 2010 is the payments-service rate limit; code 2026 is the WaaS2 platform-level rate limit. Both are returned with HTTP 429. |
| 2023 | API request signature is missing or invalid. | <ul><li>Ensure your request timestamp is within 30 seconds of the server time.</li><li>Verify the request body is serialized with keys in the correct, consistent order.</li><li>Confirm you are using the key pair that corresponds to the current environment (development vs. production).</li></ul>For details, see <a href="/payments/en/developer-tools/get-started-with-api">Send your first request</a>. |
| 2024 | API key authentication failed. | <ul><li>Use the API key that corresponds to the current environment (e.g., use a development API key in the development environment and a production API key in the production environment).</li><li>Ensure that the API key you are using is registered in the Cobo Portal and is in active status.</li><li>If your API key is permanent, make sure the request originates from a whitelisted IP address.</li><li>Ensure your API key is activated. Newly created API keys may require activation in Cobo Portal before they can be used.</li></ul>For details, see <a href="/payments/en/developer-tools/get-started-with-api">Send your first request</a>. |
| 2028 | The requested resource was not found. | <ul><li>Verify the resource identifier is correct and has not been miscopied.</li><li>Ensure the resource was created successfully before referencing it in another request.</li><li>Confirm the API key belongs to the same organization that owns the resource.</li></ul>Note: Error 2028 appears in the JSON response body when the API endpoint is valid but the resource is missing. HTTP 404 means the endpoint URL itself is incorrect. |
| 2050 | No available pricing plan, or the operation usage limit has been exceeded. | Contact Cobo sales to review or upgrade your plan. |
| 2051 | Your pricing plan has expired. | Renew or upgrade through Cobo Portal or contact Cobo sales. |
| 2052 | Your plan's usage limit has been exceeded. | Contact Cobo sales to upgrade your plan. |
| 3000 | Test-token claim quota exhausted. | Your organization has reached the maximum of 10 test-token claims allowed per organization in the development environment. Contact Cobo support to request an increase to your test-token claim quota. |
| 4001 | Forbidden access to the requested resource. | <ul><li>Your API key lacks the required permission for this endpoint.</li><li>The API key was created in a different environment (development vs. production).</li><li>The resource belongs to a different organization.</li><li>You are accessing a feature not included in your current plan.</li></ul>Refer to <a href="/payments/en/guides/roles-and-permissions">Roles and permissions</a> for the full permission matrix. |
| 4002 | Organization payment service status is invalid. | <ul><li>Log in to Cobo Portal and check your payment service account status.</li><li>If the account is pending, wait for approval or contact your Cobo account manager.</li><li>If the account has been suspended, contact Cobo support for assistance.</li></ul> |

### HTTP status codes

| Status code | Description        | Solution                                    |
| --------------- | ---------------------- | ----------------------------------------------- |
| 200             | OK.                    | N/A              |
| 400             | Bad request.           | Check the request parameters.                   |
| 401             | Unauthorized.          | Check the API key, API signature, or timestamp. |
| 403             | Forbidden.             | Ensure you have the required permissions.       |
| 404             | Not Found.             | Check the request URL.                           |
| 405             | Method Not Allowed.    | Use a supported HTTP method.                    |
| 406             | Not Acceptable.        | Ensure the request content format is JSON.      |
| 429             | Too Many Requests.     | Reduce request frequency and try again later. See business error codes 2010 and 2026 for details.   |
| 500             | Internal Server Error. This error can be caused by several issues.| Check your server configuration settings and try again later.                              |
| 502             | Bad Gateway.           | Check the connectivity and try again later.     |
| 503             | Service Unavailable.   | Try again later.                                |
