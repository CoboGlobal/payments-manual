---
title: "Unexpected deposits"
lang: "en"
---

An unexpected deposit is a transaction not within current orders/deposit plans, or a deposit in an unsupported token. It is not credited to any payer or order. Read [Events overview](/payments/en/guides/events/overview) first for the envelope, deduplication, and the rules that apply to every event.

## Events on this page

| Event | What it notifies you of | Type |
| --- | --- | --- |
| [`payment.transaction.external.created`](#payment-transaction-external-created) | An unexpected deposit was detected. | **Standard** |
| [`payment.transaction.external.completed`](#payment-transaction-external-completed) | The unexpected deposit cleared compliance screening. | **Standard** |

## `payment.transaction.external.created`

### Trigger conditions

Fires when an unexpected deposit is detected (transactions not within current orders/deposit plans, or deposits in unsupported tokens). The funds are not credited yet; record the deposit as unattributed. Deposits at or below the dust threshold (default 0.05) do not produce events.

### Event content

The key fields are below. For the complete list, see [Transaction fields](/payments/en/guides/events/advanced#transaction-fields).

<div className="field-table">

| Field | Type | Description |
| --- | --- | --- |
| `data_type` | `string` | Always `PaymentTransaction`. |
| `transaction_id` | `string` | The deposit's ID in Cobo. |
| `status` | `string` | The transaction status. |
| `chain_id` | `string` | **Optional.** The chain the deposit arrived on. |
| `token_id` | `string` | **Optional.** The token the deposit arrived in. **An unsupported token is one of the common reasons a deposit ends up here**, so this can name a token you have not enabled. |
| `transaction_hash` | `string` | **Optional.** The on-chain hash. |
| `source` | `object` | Where the funds came from, typically an external address. Use it if you return them. |
| `source.addresses` | `array` | The sender addresses. |
| `destination` | `object` | Where the funds went. |
| `destination.address` | `string` | The receiving address. |
| `destination.amount` | `string` | The amount received. |
| `destination.memo` | `string` | **Optional.** The memo, on chains that use one. |
| `created_timestamp` | `integer` | When the deposit was created, in Unix timestamp (milliseconds). |
| `updated_timestamp` | `integer` | When the deposit last changed status, in Unix timestamp (milliseconds). |

</div>
